# 🏦 Banking Management System

A console-based Banking Management System developed using **Python and Object-Oriented Programming (OOP)**. This project simulates basic banking operations with separate functionalities for bank administrators and customers.

## 🚀 Features

### 👤 User Features
- Register a new bank account.
- Login using name and password.
- Check current account balance.
- Deposit money.
- Withdraw money.
- Apply for a loan.
- View transaction history.
- Logout securely.

### 🛡️ Admin Features
- Create new user accounts.
- Delete existing user accounts.
- View all registered users.
- Check the total bank balance.
- Check the total loan amount.
- Enable or disable loan facilities.
- Declare the bank bankrupt.
- Logout from the admin panel.

## 🧠 OOP Concepts Used

- **Classes and Objects:** Separate classes for `Bank` and `Account`.
- **Encapsulation:** Organizing account information and banking operations within classes.
- **Methods:** Implementing deposit, withdrawal, loan, and account management operations.
- **Class Attributes and Instance Attributes:** Managing shared and individual banking data.
- **Composition:** The Bank class manages a collection of Account objects.

## 🛠️ Technologies Used

- Python 3
- Random Module
- Object-Oriented Programming (OOP)
